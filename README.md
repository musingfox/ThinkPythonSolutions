# Think Python 3e 練習解答集（繁體中文版）

這是《Think Python 3e》書籍的練習解答集，已完整翻譯成繁體中文，專為台灣和使用繁體中文的學習者設計。

## 📖 關於本專案

本專案將原本的英文 Think Python 練習解答翻譯為繁體中文，使用符合台灣慣用的程式設計術語和表達方式。所有的 Jupyter Notebook 檔案都已翻譯，但保持程式碼部分不變，確保學習者能夠理解概念的同時，也能熟悉國際通用的程式語言語法。

## 🎯 適合對象

- 完全沒有程式設計經驗的初學者
- 想要學習 Python 的中文使用者
- 需要中文解釋的程式概念學習者
- 教授 Python 課程的老師

- **第1章**：歡迎 - Python 入門

- **第3章**：函式 - 程式模組化
- **第4章**：函數和介面 - 設計原則

## 🚀 快速開始

### 選項1：線上使用 (推薦初學者)
1. 前往 [Google Colab](https://colab.research.google.com)
2. 點選「GitHub」分頁
3. 輸入此 repository 的 URL
4. 選擇想要學習的章節檔案

### 選項2：本地安裝
詳細的環境建置指南請參考 [學習指南.md](學習指南.md)

```bash
# 下載專案
git clone https://github.com/你的用戶名/ThinkPythonSolutions.git
cd ThinkPythonSolutions

# 安裝 Jupyter
pip3 install jupyter

# 啟動 Jupyter Notebook
jupyter notebook
```

## 📋 學習建議

1. **按順序學習**：建議依照章節順序進行，每章都建立在前一章的基礎上
2. **動手實作**：不要只是閱讀，一定要執行和修改程式碼
3. **完成練習**：每章末尾的練習是鞏固學習的重要部分
4. **尋求幫助**：遇到問題時，可以使用 AI 助手或加入學習社群
